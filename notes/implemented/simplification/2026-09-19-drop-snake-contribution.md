# Agent Note: 首屏贡献图整体移除，换成「最近在做什么」

## 问题

复刻对象的首页首屏有一张 Platane/snk 生成的 **GitHub 贡献图贪吃蛇**，
视觉上很讨喜，也是那个站点最有辨识度的一块。

但它是**复刻对象站长本人的贡献数据**。直接留着，等于在我的个人主页上
展示别人的提交记录 —— 和页脚冒用备案号是同一类问题。

## 决策

先尝试「换成自己的数据」，用 GitHub GraphQL 把真实贡献拉出来看：

- 53 周 / 371 天里只有 **6 天**有提交（**1.6%**）
- 全年 **20 次**提交，单日最高 7 次

一条蛇爬在 98.4% 空白的灰格子上，看起来像坏了。

所以**整个模块换掉**，改成「最近在做什么」：显示最近推送的 4 个仓库，
带语言色点和相对时间。数据构建期生成（见[第三方 API 改到构建期取数](2026-09-20-github-api-egress-limit.md)）。

新容器保留原图的 `880 / 192` 宽高比：

```css
.recent { aspect-ratio: 880 / 192; width: 85%; }
```

这样桌面端占位完全没变，而且接口挂了也不会塌版 —— 高度由 CSS 撑着，只换内容。

## 曾考虑的替代方案

**保留原图，加一行「示意图」小字标注**——否决。标注解决的是「误导」，
但解决不了「我的主页上挂着别人的数据」这件事。而且那张图是首屏最大的视觉元素，
存在感比标注强得多。

**换成自己的贡献图**——否决。数据已经拉出来了，1.6% 的填充率，
效果比「不显示」差。而且 `@platane/snk` **不在 npm 上**（它是 GitHub Action），
本地根本跑不了，要走 CI，改造成本还更高。
（这条被单独记成了[不换自己的 GitHub 贡献图](2026-09-19-own-contribution-graph.md)）

**直接删掉，首屏留白**——否决。那一块是首屏唯一的「动态内容」，
删了首页就变成一个纯静态的自我介绍，失去了「还在更新」的信号。

## 后果

- 首页不再展示任何他人的数据。
- 代价：**丢掉了那张图最有价值的部分 —— 视觉上的趣味性**。
  「最近在做什么」是一块文字列表，比贪吃蛇平淡得多。这是明知的选择：
  宁可平淡，也不要挂别人的数据。
- 顺带清理：`snake-Light.svg` / `snake-Dark.svg` 两个文件从仓库移除。
  其中 `snake-Dark.svg` 在原站本来就是**死资源** ——
  唯一会换图的那段脚本读的是那个只写不读的死 cookie。
- 版式影响：页面总高 1118 → 1115。差 3px 是因为原图是行内 `<img>`
  （底部有基线间隙），新块是 flex 容器。**不是回归**，已重设基准。
